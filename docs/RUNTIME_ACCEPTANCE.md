## 核对方法和边界

[赔率表 JSON](../fixtures/customer-plays.json) 可直接在配置页预览导入，Ubuntu 托管工件包含此文件。默认关闭复式，统一 **10%** 反水；另设二中二含特：两平码 55 倍、一特一平 25 倍。普通二中二为两平码 60 倍；三中二为前六球至少中两个、20 倍；三中三为前六球全部命中、600 倍。四／五／六／七肖亮按全部七球的不同生肖种数判断。

独立 Python 程序使用 `itertools.combinations` 拆注及 `Decimal(ROUND_HALF_UP)` 逐注计算预期值，不将后端报价或结算函数的输出作为预期值。比较范围包含每个基础注的选项、费率、返还、反水、输赢、和局，以及整条投注、原受注／飞出／自留、投注人／受注方分类账目。

- 严格等于 5 拒绝选 7；不少于 5 和启用复式各正确拆成 21 注；候选上限阻止第二项。
- 重复／空／越界号码、非整数原金额、负数、零和超大金额均拒绝；重复请求保持幂等，换内容复用 UUID 拒绝。
- 三中二分别构造恰中两个、三个全中、一个平码加一个特码；特码不参与平码命中数。
- 0 尾单选、复式及全部不命中配置，含 0 与本命选项的组合分别计算赔率；普通和飞出金额使用 Decimal 独立核对。
- 本命赔率逐基础注应用；二中二含特按实际位置分档。规则修改、删除后历史投注仍用原快照。
- 0.05 元和 0.01 元飞出沿用原费率逐注舍入；撤销飞出不计账；原注撤销保留至客户主动清空对应历史期。
- 开始时间包含端点、封盘时间不包含端点；封盘后新增、纠正、飞出、撤销均拒绝。
- 全七球覆盖 2、4、5、6、7 种生肖；大小／单双的各范围含 49 退本且无反水，其他玩法照常计算。
- 非法重复球结果保留投注、继续等待；有效结果经实际抓取 worker 结算；重复结果不重复记账，冲突结果保留首次账目。
- 特意提供与本地表不同的生肖／波色，核验按接口数据结算及保留波色；跨 2026-12-31 至 2027-01-01 验证马转羊和所有 49 个映射。
- 关闭并重启服务，确认期次统计及原登录会话保留。

另有 Rust 独立穷举风险测试：在缩小的合法号码集合中遍历所有“六平码＋一特码”，核对生肖种数、含特码分档、正负头寸、49 退本混合场景的精确极值及示例开奖；全 49 号码集核对四种生肖亮组合。真实报价接口也核对四肖亮最大返还 15 倍、二中二含特最大返还 55 倍及对应示例。

另在限制 2 核 CPU 配额、1 GB 内存、禁用网络的 Debian 运行容器中执行五种各 10,000 注的固定风险基准，全部得到精确结果并复核示例，最慢约 1.09 秒；包含生肖种数及含特码分档的头寸场景约 26 毫秒。这不覆盖任意混合规则的最坏分布。

每期 1,000 条记录／10,000 条基础注、单次上限、并发提交、升级旧库和授权协议由独立 MySQL 测试覆盖；托管容器生命周期、备份与恢复由 Ubuntu Docker 验收覆盖。浏览器另验新增表单和可访问性。以上测试分开运行，避免共享测试库互相清空。

## 重现

按 [开发指南](DEVELOPMENT.md) 准备专用 `marksix_test` 和测试管理员密码，然后在仓库根目录执行：

```bash
cargo build --locked --manifest-path backend/Cargo.toml --example runtime_server
python3 scripts/runtime_acceptance.py
```

脚本会清空该测试库、自动启停 localhost:8082，并保存 `test-results/runtime-acceptance.json`。夹具和业务验收不启用生产授权；核销、账号绑定、到期及续期由独立托管 HTTP 测试覆盖。夹具不会打包到客户端或服务器镜像。

本验收不代表真实开奖网站长期可用、任意混合玩法均在一分钟内完成。
