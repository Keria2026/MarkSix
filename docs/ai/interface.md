# 界面体系

## 页面职责

客户 App 管理登录、授权检查与工作台生命周期。Workspace 组合概览、录注、记录、统计及设置。运营界面使用相同的视觉基础，维护独立的登录与客户管理状态。

录注模式与模块启用状态来自客户设置。关闭模块时，相关入口、派生展示及操作均使用同一可用性来源。草稿保持账号边界；认证失效时销毁视图和未完成请求。

## 视觉来源

`frontend/src/app.css` 是当前视觉变量与公共样式来源。品牌使用深紫主色 `#4a154b`，浅色背景、柔和渐变、圆角容器与清楚的数字层级。字体资源随前端提供。

优先复用现有 Modal、选项、列表、金额及状态组件。设计调整以已运行页面和样式为依据，不引入其他产品的营销版式、专有字体或无关 token。

## 操作边界

确认弹窗应把金额、对象、玩法和需处理的问题放在同一分项范围。错误需要文字及可定位状态，不能仅依赖颜色。保留键盘操作、焦点回收、可访问名称与窄屏可用性。

页面文字只保留作出决定所需的信息。实现细节、重复副标签和流程自我解释不进入业务界面。
