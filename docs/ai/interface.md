# 界面体系

## 页面职责

客户 App 管理登录、授权检查与工作台生命周期。Workspace 组合概览、录注、记录、统计及设置。运营界面使用相同的视觉基础，维护独立的登录与客户管理状态。

协作账户通过桌面侧栏左下角头像切换记录范围；手机使用顶部头像。切换重新建立请求作用域，取消旧范围的请求并清空旧数据，避免迟到响应覆盖新视图。进入关联前记录时隐藏录注及配置入口；服务端同时拒绝修改。当前处于录入页时，范围选择明确提示切换会关闭当前录入页面。

概览、统计、历史和导出以录入业务日期合并港澳账目，每条投注保留市场标记。两个市场的开奖使用相同卡片呈现，未开奖分项显示待结算。

录注模式与模块启用状态来自客户设置。关闭模块时，相关入口、派生展示及操作均使用同一可用性来源。草稿保持账号边界；认证失效时销毁视图和未完成请求。

## 视觉来源

`frontend/src/app.css` 是当前视觉变量与公共样式来源。界面使用蓝色操作主色 `#2457c5`、中性浅灰背景与不透明白色面板。主要文字为深灰，盈亏和异常保留语义色，不以装饰性渐变和阴影争夺注意力。系统中文字体优先；导出字体资源随前端提供。

手机底栏使用浮动胶囊玻璃材质，静止选中胶囊收在底栏内部；按压和切换时鼓起、滑动并缩放回弹，快速轻点也播放完整过渡，结束或取消后恢复原尺寸。横向拖动释放后由原导航按钮切换页面，取消拖动保持当前页。光学位移图只生成于手机布局或尺寸变化，桌面侧栏不启用这层效果。减少动态效果、减少透明度和高对比度偏好使用对应回退；正文按底栏、展开菜单和底部安全区实际占用留白。

正文与输入保持 14px 阅读尺度，辅助文字不低于 12px；手机输入为 16px。常用操作与筛选控件至少 44px，表格金额使用等宽数字并右对齐。桌面与平板导航显示文字，手机底部导航按实际高度为正文留出空间。页面切换不淡出正文。

优先复用现有 Modal、选项、列表、金额及状态组件。设计调整以已运行页面和样式为依据，不引入其他产品的营销版式、专有字体或无关 token。

## 操作边界

确认弹窗应把金额、对象、玩法和需处理的问题放在同一分项范围。错误需要文字及可定位状态，不能仅依赖颜色。保留键盘操作、焦点回收、可访问名称与窄屏可用性。

页面文字只保留作出决定所需的信息。实现细节、重复副标签和流程自我解释不进入业务界面。

记录筛选使用本地草稿，投注人、玩法、金额和排序统一点击“筛选”应用；后台刷新只使用已应用条件。多选面板支持搜索、Escape 关闭及焦点回收。空账本和筛选无结果提供不同的下一步。

手工录注使用原生单选控件直接切换港澳市场，摘要显示市场与提交前缺失的信息。统计表头统一选择账单格式；批量导出下载压缩包，行内导出仅下载对应投注人的 PDF、PNG 或 Excel 文件。Excel 结账表按投注单合并港澳分项，使用“序号、总单、水、中、结账”五列与底部总数；结账采用受注方方向（本金减返水、减中奖），未结算金额明确保留未知状态。导出进度、取消与失败提示使用可关闭的浮动提示，不能改变表头或数据行的位置。

桌面工作区随侧栏外的可用宽度伸展，表格和统计卡片共用左右边界；窄屏数据表格在自身区域内横向滚动，不撑宽整页。

## 首页受注分布

首页保留总账摘要和港澳开奖，下方以特码、一肖中、尾中切换显示受注分布；默认每项单行展示，可切换为三列网格。切换板块或刷新数据保留当前展示方式。本期统计及历史页面在全部受注统计中展示投注人明细，仅展示本方受注净盈亏；投注记录单独保留。

分布按录入业务日期合并港澳、汇总所有投注人的原受注本金，不扣飞出。服务端按基础注快照归类，重复基础注与包肖余分均保留，撤销及和局退款不计。规则名称或费率版本不改变相同语义的归类；组合注与不中玩法不混入单项命中玩法。

均值分别以49、12、10项为分母，包含未受注项。金额保持整数分，超均值比较使用精确比例，显示均值与超出金额保留到分。加载失败显示错误和重试入口，不以全零掩盖失败；旧请求不能覆盖切换后的日期或账号。
