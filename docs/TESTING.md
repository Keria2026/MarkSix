# v0.2 验证范围

验证命令见 [开发指南](DEVELOPMENT.md)。当前版本的交付以 **dev 分支同一提交的 CI 与 Windows Native 两个工作流均成功**为准；安装工件只在对应验收通过后上传。v0.1 报告已移入 archive，不代表新版验证结果。

## 业务与数据

- 14 项 Rust 单元测试覆盖定点金额与溢出、复式、多选阈值、年度换肖、本命费率、范围、特碰／软碰、三中二、49 退本、旧快照、严格开奖校验及风险取消／超时。
- 精确引擎与独立穷举对照：18 组原混合案例，加 9 组含正负头寸、配对、最少命中及 49 退本的新案例；同时复核两个极值示例开奖。
- MySQL 8.4 完整事务流程：重复／并发提交、版本冲突、容量边界、撤销保留历史、配置快照、金额纠正、超额飞出拒绝、飞出撤销、封盘限制、重复开奖和恢复。
- 财务验算：原受注 150 元、飞出 40 元、赔率 2、反水 2%，中奖后的原受注 −153 元、飞出 +40.80 元、自留 −112.20 元。额外大小注遇 49 后本金退回，不影响有效本金或反水。
- 升级测试真实创建 v0.1 表结构和旧 JSON，执行生产迁移，检查规则及基础注没有改写、旧单双快照仍按原语义结算，重复启动不重复迁移。

## 前端与部署验收

浏览器测试覆盖管理员登录、复式默认隐藏／配置启用、7 选 5 预览和提交、投注人、金额修改、飞出与统计、金额筛选、撤销、玩法配置、历史导航、官方 iframe、接口波色优先及手机导航。测试记录页面截图，Axe 扫描 WCAG A/AA，检查横向溢出和未捕获 JS 错误。

Ubuntu CI 构建并启动三服务镜像，打包后复验文件 SHA256、导入镜像、健康状态、停止／启动和备份。Windows Native 在 Windows PowerShell 5.1 下使用中文且带空格的安装／数据路径，实际验证数据库初始化、网页登录、前端、复式预览、备份、重启及会话／凭据保留。

## 性能与边界

`risk_bench` 使用确定性的 10,000 基础注场景，逐一复核极值示例。v0.2 本地 release 首轮三组实测：号码特码 <1 ms、生肖复式 11 ms、混合 997 ms；这些结果来自当前云开发机，不能冒充独立 2 vCPU／1 GB 机器的完整性能验收。

另有包含特碰／软碰、三中二、大小退本及飞出头寸的固定基准，由同一工具和 CI 执行。任意高分散的组合仍可能超过 60 秒；此时只发布超时状态，不发布近似极值。

尚未覆盖长期真实开奖持续运行、Safari／Firefox 与辅助技术手工验收，以及所有可能玩法分布在 2 vCPU／1 GB 机器上的最坏情况。官方网页是否允许内嵌和外部开奖服务可用性由对方控制，应用提供新窗口入口和抓取异常状态。
