# Dev1.0 验证范围

发布依据为 dev 同一提交的 CI 验证与 Linux 容器验收。只有 master push 且验证成功才允许部署。交付、测试与部署均以 Ubuntu 托管版为准。

## 必须覆盖

- 业务金额、规则、组合、快照、飞出、退本及精确极值。
- 0 尾逐注赔率、本命重叠优先级、配置快照、飞出与金额修改后的舍入。
- 投注人／玩法多选、投注总额升降序、非法排序参数、分页及自动刷新。
- 历史清空的密码、确认文字、会话、幂等、跨客户隔离、保留本期及备份删除／恢复阻止。
- 清空响应丢失时，同一弹窗内重试沿用请求编号；取消、关闭或 Escape 后重新打开必须生成新编号。
- 恢复预检拒绝不停止网站；停服后二次预检失败恢复服务；已开始修改数据库后的失败保持停机。
- Python 3.10 下的工件校验、篡改／缺失文件拒绝及大文件分块摘要计算。
- 应用只输出 error、Nginx 关闭访问日志及 Docker 日志轮转。
- 真实 MySQL 事务与历史数据库向前迁移；不改写历史快照。
- 托管账号的数据库权限隔离、跨客户 API 访问、单会话、密码变更和到期边界。
- 激活码账号绑定、并发核销、重试幂等、提前续期、永久授权及停用。
- 到期后旧投注结算，以及永久删除业务、账号和相关备份。
- Nginx 双域名、HTTPS Cookie、Web 管理流程、可访问性及窄屏。
- 容器启动、停止、备份、恢复、更新失败处理与 200 在线目标。

测试命令见 [开发指南](DEVELOPMENT.md)。通过、失败、跳过、未执行必须分别记录。未连接 VPS 时不能宣称生产部署完成；本地证书测试不能代替公网证书与 Cloudflare 验证。

本版实际结果和未验证范围见 [Dev1.0 验收记录](DEV1_ACCEPTANCE.md)。
