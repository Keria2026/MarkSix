# v0.3 验证范围

验证命令见 [开发指南](DEVELOPMENT.md)。交付标准为 **dev 分支同一提交的 CI 与 Windows Native 两个工作流均成功**，部署包只在对应验收完成后上传。

## 业务、迁移与授权

- Rust 单元测试覆盖定点金额及溢出、复式与普通多选、候选上限、年度换肖、本命费率、范围、碰号、三中二、生肖种数、二中二含特分档、49 退本、旧快照、严格开奖校验、风险取消／超时、授权签名篡改与 HTTPS 地址校验。
- 精确引擎与独立穷举对照：18 组原混合案例和 9 组含正负头寸、配对、最少命中、49 退本的新案例，复核两个极值开奖。
- MySQL 8.4 事务流程覆盖重复／并发提交、版本冲突、容量边界、撤销与审计、快照、金额纠正、飞出、封盘和重复开奖；新增玩法导入失败整批回滚、导入独立 ID、删除版本冲突、删除不影响历史引用及不能再编辑已删玩法。
- 升级测试真实创建 v0.1 表及旧 JSON，执行所有生产迁移，验证原快照不改写、旧单双按原语义结算，重复启动不重复迁移；该路径也依次经过已发布 v0.2 迁移。
- 独立授权 HTTP 协议测试使用临时随机密钥：两个设备并发核销同一码仅一个成功、同绑定重试不延长有效期、换设备／密码失败、到期失败、新码续期、在线撤销。生产私钥不进入测试或 CI。

## 浏览器流程

Chromium 完整流程包含登录、复式默认关闭和显式启用、7 选 5 提交、投注人、金额纠正、飞出与分类统计、金额筛选、撤销、玩法编辑、按名称自动匹配、越界点击阻止、单条导出及预览导入删除、历史导航、官方 iframe 和接口波色优先。新增表单流程覆盖生肖种数创建／自动选择及二中二含特赔率保存。另一个流程验证激活界面、激活成功进入及过期返回授权页。

Axe 检查手机概览与激活页的 WCAG A/AA，检查 320px 窄屏导航的 44px 触控目标、短标签、页面横向溢出和未捕获 JS 错误，保留截图与失败追踪。

## 赔率表真实运行

Actions 运行独立的 Python Decimal 核对脚本，真实 HTTP／MySQL／worker，固定随机种子与可控开奖源。逐注核算、飞出舍入、全部及分类账目、元旦换肖、异常开奖与历史快照均有断言。完整数据与可复现命令见 [运行验收](RUNTIME_ACCEPTANCE.md)，每次成功运行上传 `runtime-acceptance` JSON 工件。

## 两端运维验收

- Ubuntu CI 构建实际镜像，启动三服务，打包并验证 SHA256、导入镜像、健康状态、重复停止、重启、备份和恢复。另实际启动授权服务，测试发码与公钥工具。CI 使用的临时测试私钥在上传前删除，不与客户端公钥匹配。
- Windows Native 在 PowerShell 5.1 使用中文和带空格的程序／数据路径，实际验证初始化、登录、未激活 402、前端、丢失 app PID 和失效 MySQL PID 时安全停止、两个端口释放、重复停止、重启、凭据／会话保留，以及完整 .sql.gz 恢复。
- Windows 的生产二进制保持授权强制开启；业务流程与真实授权核销分别由数据库及协议测试验证，不向 Windows 安装测试泄露生产签发私钥。

## 性能和实际边界

`risk_bench` 对五种确定性的 10,000 基础注场景计算精确极值并复核示例；包含生肖种数及二中二含特正负头寸。2026-10-15 在 Docker 限制 2 核 CPU 配额／1 GB 内存的 Linux 容器中，五项分别约 1、14、1089、11、26 毫秒；这不构成独立 Ubuntu 机器上任意配置的性能保证。任意高分散组合仍可能超过 60 秒，此时只显示超时，不显示估算。

尚未覆盖长期真实开奖持续运行、Safari／Firefox 与辅助技术手工验收，以及所有玩法分布的最坏情况。Windows 测试包含中文路径模拟，但不能代替每种 Windows 用户配置和组织安全策略下的实机检查。外部开奖及官方网页可用性由对方控制。授权需要自建可用的 HTTPS 服务，不能保证本地程序不可逆向或设备标识不可克隆。
