## 容器与工件

真实 Nginx／MySQL／应用运行镜像验收覆盖双域名 TLS、Secure Cookie、客户数据库权限隔离、激活与单会话、冷备份恢复、旧会话失效、重复停止启动、历史清空及旧备份拒绝、永久删除和移动端管理流程。

本地采用已编译的当前 Linux release 二进制和前端生产构建组装运行镜像，以避免云环境 VFS 存储重复展开完整 Rust 构建层；未把它表述为本地执行过正式多阶段 Dockerfile。正式 Dockerfile 的构建、托管验收与同工件发布由该提交的 GitHub Actions 执行。工件包含提交、镜像展开预算、迁移契约和 SHA-256 清单，不包含生产配置或密钥。

最终本地容器验收：13 项通过，215.59 秒；包含另行执行的 1 项真实托管浏览器流程。使用 2 个隔离账号验证功能，未执行并发负载；auth 测试 UID 为 1000，正式 UID 10001 由 root CI 验证。验收结束确认包括 maintenance profile 的工具容器均已清理，已有服务与数据卷保留。

最终本地 Ubuntu 工件：23 个文件、8 项迁移契约，压缩镜像 292,296,813 字节；verify.py 校验及敏感文件排除检查通过。测试标签为 v1-final-review，仅作本地验收。GitHub Actions 使用完整提交 SHA 重新构建并打包正式工件；其状态以 PR 检查为准。

## 发布边界

本轮不代表真实 VPS、公网 Cloudflare 路由、真实 iOS Safari 或 200 个满额账本混合负载已经重新验收。固定风险基准不能代表任意玩法混合的最坏分布；超时必须显示，不能发布估算结果。容量目标与已验证能力分别记录。

首次升级到本版须刷新已打开的浏览器页面。旧 GET 投注筛选已移除，POST 筛选使用真正 JSON 数组。此次迁移增加了数据库契约，不能承诺直接回退到缺少契约元数据的旧版本；恢复边界及命令以 [VPS 指南](../deploy/vps/README.md) 为准。
