## 新增功能证据

- 排序保存、刷新后沿用、导出顺序一致，规则版本不变；重复／过期目标被拒绝。
- 组合单任一分项非法整单回滚；并发重复提交只生成一单。浏览器实际模拟“服务器已入账、响应丢失”，切页后使用原提交编号重试，列表仍只有一单。
- 分项金额纠正、飞出、部分撤销、整单撤销及版本冲突验证通过；单次 1,000 条和每期 10,000 条基础注边界通过，撤销后容量释放。原业务回归继续验证分项记录上限。
- 自助改密：原密码错误不修改账号或退出；成功后原密码和旧会话失效，已授权截止日及永久授权保留，旧未使用码失效，其他客户不受影响。真实 TLS 浏览器验证转发、错误密码提示、退出与新密码重新登录通过，并核对改密前后授权截止日一致。
- PDF 下载包含全部投注人，大小写冲突、Windows 保留名、路径字符及 UTF-8 长名称验证通过。中文字体只在导出时加载，使用带摘要 URL；字体字形偏移增加防回归检查。
- 320、390、768、1440 像素实际核查组合单长投注人代号、排序和改密窗口，无横向溢出；截图保存在本地 test-results。

组合算例使用独立配置：一肖普通 2 倍、本命马 1.8 倍；二有普通 4 倍、本命组合 3.5 倍；特码 43 倍；全部反水 10%。虎 200、马 400、马虎二有 500、44／10／9 各 10、4／1／8 各 20，合计 9 条基础注、本金 1,190 元。以 `[1,5,9,10,44,4,8]` 开奖，含本返还 3,730 元、反水 119 元，投注人净盈利 2,659 元。马分项飞出每注 100 元后，本方飞出盈利 90 元、自留净额 −2,569 元，原投注人账目不变。

实际从服务端导出此算例并生成中文 PDF，约 26 KB、2 页；文本提取、字形解析和整页渲染核对通过，包含取消分项且不计总额。独立财务核对另覆盖 33 条默认规则、12 条补充规则、1,382 条投注、2,582 条基础注、220 条飞出及 10 期。

Actions 工件清理已经实际执行：继先前删除 170 个历史工件后，再删除两份 Docker 调试记录，保留最近上线版本的安装包及两份验收报告。再次预览无待删工件。自动保留规则见 [VPS 指南](../deploy/vps/README.md#actions-工件清理)；新增清理工作流和 CI 均经 actionlint 校验。

## 容器、交付及边界

本地容器使用本轮编译的 release 程序和前端生产产物，覆盖到已有缓存运行时镜像；13 项双域名 TLS、客户生命周期、备份恢复、历史清空及实际浏览器流程通过，测试容器和卷已清理，原有服务保留。本地 auth 使用 UID 1000 适配测试备份目录，仅验证两个独立客户，不冒充生产 UID 或 200 人负载验收。

正式多阶段镜像、生产 UID 10001 和 Ubuntu 工件仍须由本提交的 Actions 完成验证，结果以 PR Checks 与 hosted-acceptance 工件为准。CI 继续执行固定 2 CPU／1 GB 风险基准；本轮未在本机重复该基准，不把旧结果冒充当前性能。

0009 为增量迁移，增加排序和组合单关联，原始规则与金额快照保留。升级前冷备份，跨迁移契约回退须恢复匹配数据，不能承诺直接无损回退。部署操作仅在 [VPS 指南](../deploy/vps/README.md) 维护。

本轮不代表真实 VPS、公网 Cloudflare、真实 iOS Safari 或 200 个满额账本混合负载已经重新验收。浏览器手机模拟与字体渲染核查不替代真实设备验收。
