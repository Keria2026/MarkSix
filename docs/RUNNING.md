# Dev1.0 部署与维护

唯一部署入口为 [VPS / Actions / Docker / Nginx 指南](../deploy/vps/README.md)，包含首次配置、双域名 HTTPS、GitHub Secrets、更新、备份、恢复、日志及失败处理。

客户只访问网站。dev 验证后由运营方合并 master，Actions 成功才部署同一次构建工件；不在 VPS 现场构建。Ubuntu 工件仅包含托管部署文件、三份已测试镜像和玩法配置示例。

客户在“玩法与配置 → 清空我的历史记录”验证密码并输入确认文字，可永久删除本期之前的数据及该客户的托管备份。本期数据和配置不受影响。历史清空不可恢复；含清空前记录的旧全量备份禁止恢复，运营方应重新生成完整备份。不要删除 backups/erasures 中的非实名清空凭据。
