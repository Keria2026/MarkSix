# Dev1.0 验收记录

日期：2026-10-15。验收环境为 Codex 云端工作区的真实 MySQL、Docker Compose、Nginx 和 Chromium；**尚未连接或部署生产 VPS**。旧本机安装、数据库、备份和签名密钥独立保留。

## 业务和账号

Rust 格式、Clippy、前端类型检查、构建和格式检查通过。真实数据库测试覆盖历史迁移、投注事务、旧授权兼容和托管账号流程。

按客户赔率表运行真实 HTTP 录注和结算：33 个客户玩法、9 个补充玩法，随机种子 20261015；1,292 条投注、2,492 条基础注、200 条飞出、10 期结算，26,493 项独立核对，0 差异。完整范围见 [赔率验收](RUNTIME_ACCEPTANCE.md)。

托管事务测试验证独立数据库权限、跨客户访问拒绝、单会话、凭据变更、激活码账号绑定、并发核销和重试幂等、提前续期、到期后旧投注结算、永久授权停用、客户及备份删除。队列边界测试验证：封盘前服务器收到、封盘后才进入处理的提交仍按接收时刻判断。热缓存验证超过 12 个账本后的淘汰、在用账本保护及连接释放。

## 镜像与运维

本地 Ubuntu 工件由实际后端、前端及 MySQL 镜像打包，SHA256 完整性校验通过。包内不包含私有配置、证书私钥、数据库备份或旧签名密钥。

200 个独立客户库的完整容器验收通过：双域名 TLS、Secure/HttpOnly Cookie、账号绑定激活、客户 Cookie 无法访问管理 API、单会话、冷备份与恢复、恢复后旧会话失效、重复停止与启动、永久删除客户及其备份。

Chromium 验证管理后台创建客户、签发激活码、客户激活、新登录替换旧会话及删除客户；桌面和 320 像素窄屏的 Axe 检查通过。原工作台的三个浏览器用例也通过。

## 尚未验收的生产条件

- VPS 的 Ubuntu 版本、真实 1 GB 物理内存压力、磁盘与网络。
- SSH 部署权限、GitHub production Secrets、master 分支保护。
- 公网 ACME 证书申请、Cloudflare 规则、双域名公开访问及 systemd 定时器。
- 200 个客户各自满额账本同时写入和执行极值计算。空账本在线轮询不能证明该负载的性能。

合并 master 前，必须接通服务器并完成一次性配置；本地测试通过不能替代真实 VPS 验收。dev 测试与构建不触发生产部署。
