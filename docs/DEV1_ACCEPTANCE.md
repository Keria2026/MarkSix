# Dev1.0 验收记录

## 当前功能回归（2026-10-15）

本次在独立测试 MySQL、实际 HTTP、Docker Compose、Nginx 和 Chromium 上运行；不修改生产数据，不触发发布。

- Rust 单元测试 20 项通过；另显式执行数据库升级、业务事务、托管隔离三个数据库测试，全部通过。Clippy、格式检查通过。
- 33 个客户玩法和 12 个补充玩法，1,382 条投注、2,582 条基础注、220 条飞出、10 期结算，独立 Decimal 核对 27,959 项，0 差异，35.90 秒。包含 0 尾普通、复式、不中、本命重叠、费率快照、金额修改与飞出舍入。
- 4 个客户工作台 Chromium 用例通过，含导入导出、0 尾设置、选择边界、激活续期、本期统计复选框、金额升降序、自动刷新，以及 320 像素窄屏和 Axe。
- 托管数据库测试确认：清空历史需正确密码、确认文字和当前客户会话，重复请求幂等；本期及配置保留，其他客户账本与独立备份不受影响，历史财务审计一并清除。
- 当前后端、前端 Dockerfile 均已实际构建；Ubuntu 托管工件已打包并通过 SHA-256 完整性检查，仅包含托管文件、玩法夹具和三份镜像。

托管整体验收全部通过（200.18 秒）：双域名 TLS、单会话、冷备份与恢复、重复停止／启动、清空内部调用及幂等、客户备份删除、旧代次恢复拦截、仅 error 日志，以及管理端真实浏览器创建／激活／清空／删除客户。此次本地授权容器 UID 为 1000；CI 以生产 UID 10001 再验收。合计 5 个浏览器用例通过。

生产仍由运营方合并 master 后发布。本地回归不等于已把本次更新部署到 VPS。
