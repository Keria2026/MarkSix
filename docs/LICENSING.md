# 账号授权

运营方在 admin.3801.win 创建客户账号和密码，初始化独立账本，再签发账号专用激活码。客户只访问网站，不绑定本机硬件。

## 激活与续期

- 激活码为 MSH1 开头的 256 位随机令牌，控制库只保存 SHA256；完整码仅签发时显示。
- 每码绑定账号及凭据版本，不可跨账号使用。修改账号名或密码会退出旧会话、作废未使用旧码，保留剩余授权。
- 未激活或到期后只能进入激活页。并发核销仅一次成功；同一请求 UUID 的网络重试不会重复增加天数。
- 授权天数及激活截止日按北京时间业务期计算，每日 06:00 切期。新授权 1 天包含激活时所属期；提前续期在原截止期后累加，过期后从激活时所属期计算。
- 最后授权期至次日 06:00 前仍可录注、修改、撤销和飞出，包括开奖后操作。06:00 起禁止进入下一期，旧投注继续抓取及结算。倒计时使用同一个截止时刻。
- 权限只由服务器判断，浏览器时间和倒计时不授予权限。域名是部署配置，迁移保留控制库、客户库及核销记录。

## 会话与管理

同一客户最多一个有效会话，新登录使旧会话失效，可更换设备。客户会话 24 小时，后台会话 8 小时；生产 Cookie 限当前主机、HttpOnly、Secure、SameSite=Strict。

后台超级管理员管理所有客户与授权。永久授权客户仅免到期限制，仍遵守业务规则和容量限制，也可被停用。撤销授权立即失效并作废未使用码，客户须获取新码。

永久删除须输入客户账号确认，清除账号、业务库、数据库用户、会话、激活码及服务器管理的相关备份。旧控制库备份含账号资料，一并清除；其他客户的独立账本备份保留。仅保留非实名删除凭据，服务器外另存副本由持有人处理。

初始管理员通过服务器私有配置创建，没有公开默认密码。见 [部署指南](../deploy/vps/README.md)。

## 交付范围

当前只支持 Ubuntu Docker 托管网站，不再提供设备签名协议、本机授权 CLI 或 Windows 安装包。授权码由 auth 管理端生成；域名与服务器迁移须完整迁移控制库、客户库和核销状态。

## 客户自行改密

客户可在配置设置或待激活页面修改自己的密码，必须验证原密码；新密码至少 12 个字符、不超过 256 字节，且不能与原密码相同。错误验证受既有认证限流约束，不修改账号或退出当前会话。成功后递增凭据版本、使全部旧登录会话失效，并撤销尚未使用的旧激活码；已激活期限及永久授权不变。客户需使用新密码重新登录。

密码由 auth 持有的权限修改。MarkSix 仅转发当前会话的请求到固定内部地址，不接受请求指定账号或目标服务器。保存时再次锁定账号并核对原凭据版本及有效会话；并发改密、停用或登录替换会使旧请求被拒绝。审计只记录账号标识和操作，不记录密码。
