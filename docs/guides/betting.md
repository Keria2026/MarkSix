# 投注与账本规则

客户是使用 MarkSix 录账的盘口方；投注人是客户手工登记的姓名或代号。系统不提供投注人自助下注或支付。术语见[领域模型](../architecture/domain.md)，身份与权限见[账号授权](accounts.md)。

## 功能模块

入口：玩法与配置 → 配置设置 → 功能模块。开关保存到当前客户的独立业务库。

- 飞出投注默认关闭。关闭时隐藏飞出入口、受注方分类、飞出明细和自留展示；全部受注统计及概览显示原受注账目。服务端同时拒绝新增和撤销飞出。
- 手工录注与文本录注默认都开启，可分别关闭。关闭的方式不显示按钮和录入组件；两者都关闭时隐藏录入导航、概览按钮及空记录中的录入入口。
- 最近选择的录注方式按客户账号保存，刷新后继续使用；若该方式被关闭，自动使用仍开启的方式。

关闭功能保留历史记录、金额及快照，不删除或重算已经发生的飞出。重新开启后可继续查看原数据；存在有效飞出时，原有撤销和金额约束继续生效。已成功请求的幂等重放沿用原结果。

## 归期与开奖

北京时间每日 06:00 切期，期号按开奖日生成 `YYYYDDD`，闰年有第 366 期。每期录入区间为 `[开奖日 06:00, 次日 06:00)`，以服务器收到请求的时间为准，排队不改变归期。

当前期允许新增、纠正金额、飞出、撤销，包括开奖后操作。已有有效开奖结果时在同一事务内即时结算；没有结果时保留待结算。06:00 后旧期禁止新操作，但后台可以继续补齐开奖及结算。成功请求的幂等重放只返回原结果。原有记录不重新归期。

每日 21:34 起每 60 秒抓取 `https://macaumarksix.com/api/macaujc2.com`，取得本期有效结果即停止；先收到更晚有效期号或到达次日 21:34，则停止旧期抓取并标记缺失。校验期号、日期、七个不同的 1–49 号码、生肖及红／蓝／绿波色。异常不结算，冲突保留首次接受的结果。展示波色及实际结算生肖以接口为准，与本期预测映射不符时提示。

## 玩法与拆注

投注对象：号码、生肖、波色、尾数、单双、大小、生肖种数。范围：前六球平码、最后一球特码、全部七球；波色只支持特码。命中条件包括全部命中、全部不命中、至少一个、至少 N 个、特碰及软碰。同一选项在开奖中重复出现只算命中一次。

| 录入方式                    | 基础注                                                       |
| --------------------------- | ------------------------------------------------------------ |
| 单项玩法的普通多选          | 每个所选对象一注                                             |
| 普通模式，等于 5，选 7 肖   | 拒绝，必须恰好 5 肖                                          |
| 普通模式，不少于 5，选 7 肖 | C(7,5)=21 注                                                 |
| 普通模式，不多于 5，选 4 肖 | 一条 4 肖基础注                                              |
| 复式                        | 从 n 个候选取配置的 k 个，形成 C(n,k) 注；k 必须满足数量关系 |
| 包肖                        | 单号码玩法中按本期映射展开号码，每肖金额均分到对应号码       |
| 拖                          | 按下面的左右池或固定项规则生成基础注，每注使用录入金额       |

手工新建玩法默认不开复式；导入和默认配置保留文件开关。`selection_limit` 约束总候选数量，独立于基础注数量关系。选项、数量、容量和金额均由后端完整验证，不截断组合。

### 拖

仅已启用复式、每注至少两项的号码、生肖或尾数玩法提供此方式；与普通选号、包肖互斥。

- **两项玩法**：左右池各取一项，交叉组合。`06、18 拖 27、36` 为 06–27、06–36、18–27、18–36 共 4 注。
- **号码两项玩法的生肖输入**：先按本期生肖表展开号码，再左右交叉。牛拖龙各 15 元，两肖各四号码时共 16 注、本金 240 元；一侧为本命肖五号码则为 20 注。
- **多项玩法**：左边全部固定，从右边补足每注数量。三有 `鼠、牛拖龙、兔、狗` 为鼠牛龙、鼠牛兔、鼠牛狗。五有固定鼠牛、后面四肖选三，生成 4 注。
- 两边不能为空、不能重叠；API 拒绝重复或非法选项。固定项必须少于每注数量，拖项必须足够补齐。候选上限按展开号码后的总数验证，最多 1,000 注。

保存原始拖意图和展开后的基础注快照。各注独立判断特殊赔率、反水和开奖结果；后续映射或规则变更不改写它们。金额纠正和飞出继续作用于原基础注。

### 特殊判定

| 玩法             | 判定                                                                      |
| ---------------- | ------------------------------------------------------------------------- |
| 二中二           | 号码、平码、全部命中、每注 2；两号均在平码中奖                            |
| 二中二含特       | 号码、全部、每注 2；两平码使用普通赔率，一特一平使用 `special_hit_odds`   |
| 三中二           | 每注 3 项、至少命中 2；三项全中也中奖，不拆成二数组合                     |
| 生肖种数／四肖亮 | 全部七球去重后的生肖数恰好等于目标；不选择具体生肖                        |
| 特碰             | 第一个号码必须是特码，第二个必须在平码；固定顺序、关闭复式                |
| 软碰             | 两号分别在特码与平码，允许互换；两号都在平码不中奖，关闭复式              |
| 大小、单双       | 所选开奖范围含 49 时全退本金，无反水、不计有效投注；大为 25–48，小为 1–24 |

文本选项支持空白、中英文标点和全角数字；重复输入去重，未知项或越界输入禁止提交。特碰保留输入顺序。

## 生肖与费率快照

固定生肖顺序为鼠牛虎兔龙蛇马羊猴鸡狗猪。2026 马、2027 羊、2028 猴为本命；01 对应本命，号码每加一沿生肖顺序倒退一位，每十二号循环。01、13、25、37、49 均为本命号码。

元旦 06:00 当期自动轮换；管理员可安排未来生效映射，同年有效。每期固定映射用于展示和预测，实际开奖生肖取接口。

赔率最多四位小数，反水百分比最多两位。逐基础注应用普通、本命及其他特殊值，并随提交快照保存：

- 号码、生肖、尾数、大小、单双基础注含本命对应选项，可独立采用特殊赔率或反水；全部不命中玩法也适用。
- 尾数基础注含 0，可使用独立 0 尾赔率，优先于本命赔率；反水独立判断。
- 二中二含特中奖注实际包含特码时，含特码赔率优先；不与其他赔率相乘。

## 金额与操作

录入金额最少 0.1 元、最多一位小数。存储使用整数分，赔率使用缩放整数；每条基础注的含本返还、反水分别四舍五入到分，再汇总。和局、撤销无反水。

包肖仅用于单号码玩法：所选每肖各使用完整录入金额，按号码升序均分到分，余下的分优先给较小号码。100.1 元包狗 09、21、33、45，分为 25.03、25.03、25.02、25.02 元。

投注人去除首尾空白后须为 1–80 字符，不含控制字符；同名汇总且区分大小写。

- **纠正金额**：改变原每注金额；包肖改变每肖金额。保留规则及选项快照，记录前后金额、时间和版本；不得低于已有有效飞出本金。
- **飞出**：原受注不变，指定受注方，使用原注赔率反水，允许分给多方。金额最少 0.01 元，按每注填写；包肖按每肖均分并逐号检查余分，累计不得超过原注。
- **撤销**：作废并保留原记录。有有效飞出时须先撤销飞出。撤销不占有效容量、不计入汇总。

操作按期次行锁串行检查，金额修改与飞出使用 UUID 幂等及记录版本防止重复或覆盖。

## 账目与组合单

以有效本金 S、中奖含本返还 P、反水 R 计算：

| 视角       | 净盈亏                    |
| ---------- | ------------------------- |
| 投注人     | P + R − S                 |
| 本方原受注 | S − P − R                 |
| 本方飞出   | 飞出 P + 飞出 R − 飞出 S  |
| 飞出受注方 | 本方飞出净盈亏的相反数    |
| 本方自留   | 原受注净盈亏 + 飞出净盈亏 |

和局退本单列，不计有效本金和中奖返还统计。原始基础注结果和对账单保留退本。未结算显示待结算，不把预计收益当已实现输赢。自留取原受注与飞出实际舍入金额之差，不重算舍入。

组合单为同一期、同一投注人的 1–100 个独立分项，不连乘赔率。整单最多 1,000 条基础注；任一分项不合法、版本变化或跨期，整单不保存。可分项操作和整单撤销。列表按单分页，筛选金额为有效分项本金总额，玩法命中任一分项则显示完整单；统计和容量仍按基础注／分项计数。

## 页面与配置

导航只有本期概览、录入投注、本期统计、历史统计、玩法与配置。统计包含全部受注、飞出受注、投注人分类及投注记录。历史详情作为可关闭标签页；点击历史入口返回总览。

二级菜单首次收起，按账号保存用户的展开／收起选择，切换页面不改变状态；多个菜单可同时打开，只有当前页面的子项高亮。弹窗打开时锁背景操作和滚动，关闭恢复位置；动效遵守减少动态效果设置。

投注记录支持已有玩法／投注人复选筛选、本金上下限及升降序。不同筛选条件取交集、同组取并集，空选表示全部。

玩法支持名称搜索、自定义排序、JSON 导入导出、删除与批量修改通用字段。导入先预览，同名更新保留 ID 和顺序、异名新增；任何重名歧义或非法项整批拒绝。每次规则修改递增版本，历史快照不追溯。删除为关闭新录入入口的逻辑删除，保留历史引用。

新客户默认使用 [customer-plays.json](../../fixtures/customer-plays.json) 的 31 条玩法。已有账号的配置不因升级自动覆盖。配置设置还提供未来映射、改密及永久清空本期之前的历史；清空须验证密码及确认文字，保留本期和配置，相关服务器备份处理见[部署运维](../deployment/vps.md)。

## 对账导出

按当前查看期数导出全部投注人，选择 PDF 或 PNG，统一 ZIP 下载。每人一份账单，顶部只显示投注人及期号；行按录入顺序显示序号、下注本金、中奖金额、水钱（比例）、净输赢。组合单合为一行，只计有效分项，不展示玩法、对象或时间。

中奖金额含退本、不含水钱；净输赢 = 中奖金额 + 水钱 − 下注本金。水钱按基础注真实比例及已舍入金额分组，和局不计基数。末尾汇总本金、中奖金额、反水、净输赢。未结算项显示待结算、预计反水。

同一账本快照逐注／逐单／总额核对，不一致则停止导出。PDF 优先单页，超过可读空间正常分页；PNG 使用同一排版，两倍 A4 分辨率，按投注人目录及页码保存。文件名清理非法字符、重名和保留名称；取消、切期、退出终止下载。

## 风险与容量

已有开奖时预览实际收益；未开奖时投注页展示投注者最大返还／净盈利，概览展示计入飞出的自留最大可能盈亏和示例开奖结果。极值必须来自同一个合法七球结果，不能相加各注单独最大值。

每次账本变动使旧风险版本失效；后台精确计算有待计算、计算中、完成、过期、超时及失败状态，不返回估算替代值。预算 60 秒含排队，故障回收上限 75 秒；任务 ID、投注版本及待开奖状态均匹配才保存结果，失败／超时可重试。

| 容量                         | 上限                              |
| ---------------------------- | --------------------------------- |
| 每期有效分项／基础注         | 1,000／10,000                     |
| 每次提交基础注               | 1,000                             |
| 每期有效飞出记录／基础注     | 1,000／10,000                     |
| 每个账号可用玩法／单次导入   | 1,000                             |
| 单次导出投注人／分项／基础注 | 1,000／10,000／50,000，含撤销数据 |
| 导出生成文件总大小           | 128 MiB                           |

超限明确拒绝，不截断。性能实际验证范围见[测试门槛](testing.md)及[本次验证](verification.md)。
