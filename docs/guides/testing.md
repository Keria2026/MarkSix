# 测试与发布门槛

发布依据为 dev 同一提交的 CI 验证与 Linux 容器验收。只有 master push 且验证成功才允许部署。交付、测试与部署均以 Ubuntu 托管版为准。

## 自动门禁

CI 必须执行 Rust 格式／Clippy／单元测试、显式数据库升级／业务／托管隔离／风险故障测试、前端格式／类型／构建／浏览器检查、运维故障测试和独立财务核对。images 阶段另执行真实容器与 TLS 验收，同一次镜像随后打包。

Rust 锁文件通过 OSV 核对版本；前端由 `python3 scripts/audit_dependencies.py --frontend` 调用 `bun audit --json`，按 Bun 锁文件精确版本核验。扫描失败、未知公告身份或未审阅告警均阻止发布。例外仅允许 `scripts/security-exceptions.json` 明确列出的生态、包、版本及公告，且有复核期限；例外不跨版本或公告生效。

2026-10-29 复核的 deepmerge 4.3.1 例外仅限 Svelte 构建插件合并仓库配置，不接收客户或 HTTP 输入，也不进入 Nginx 运行时。上游[公告 GHSA-gcqx-w48m-w2h4](https://github.com/advisories/GHSA-gcqx-w48m-w2h4)尚无修复版本，原型污染场景已本地复现，不能声称漏洞已修复。例外到期日为 2026-11-29；新增调用方、配置可信边界或版本变化时必须重新复核。直接执行 `bun audit` 仍会显示这一条低危告警。

当前例外依据：rsa 0.9.10 仅用于 SQLx MySQL 公钥加密，不执行公告涉及的私钥运算；webpki-roots 0.26.11 只重导出已修复父包的证书；block-buffer 0.10.4 的游标是独立字段，不是公告所述的块内游标，也不存在 ReadBuffer。该缓冲区已对公告的捕获 panic 场景测试全部 256 个末字节，游标及后续使用正常。例外不适用于其他版本，依赖实现或公告变化须复核。tokio 已锁定修复版 1.53.3。

## 必须覆盖

- 领域语义语料的独立标注、训练／验证／测试隔离、确定性重建、候选生成一致性；逐字段、注数及本金核对，歧义或未知内容不能错误放行。
- 文本整单只读预览、整单原子录入、重试幂等、未知片段和缺金额阻断、手工简称学习及删除、玩法版本失效、账号隔离、超长原文不截断；HTTP 200 非 JSON 响应不得伪装为成功。
- 受限客户服务启动时校验本构建全部迁移的版本、成功标记及校验值；旧版、缺失或校验值不符时拒绝启动，不自行迁移。

- 玩法排序持久化与版本不变；组合单整批拒绝、重复提交去重、按单筛选与分页、分项修改／飞出、整单版本冲突及容量边界。
- 投注人 PDF／PNG 的中文显示、组合单与取消分项汇总、和局本金、未结算、不同水钱率及小数比例归一、逐注舍入不重算、中奖金额及末尾合计、文件名安全、共享分页与字体释放；取消不下载部分账单，汇总不一致拒绝导出；真实改密后的原密码拒绝／旧会话失效／授权保留。

- 账号 A→B、401、授权失效、延迟响应及旧弹窗清除。
- 弹窗期间的鼠标／触摸背景滚动拦截、嵌套锁及关闭恢复、动效与减少动态效果。
- 拖的 4×4 交叉组合、本命肖五号码、固定项补足、重复／重叠／非法选项、容量上限、原子组合单、快照与开奖后金额变更和飞出。
- 导航跨页不折叠用户已展开的菜单，统计与历史同时打开时不重叠；官方频道及 iframe 不存在。
- 导航文字选中态即时同步页面；快速连续切页、展开／收起菜单及跨屏宽变化后，玻璃滑块与当前菜单对齐。
- 文本选项的 Unicode 分隔、全角数字、去重、未知项、数量边界及特碰顺序；批量字段类型、清除语义、混合规则失败回滚与历史快照不变。
- 过期发布拒绝、传输前磁盘预算、工件保留及契约不符回退拒绝。
- Actions 工件清理保护最近部署尝试、上次验证部署与进行中的运行；覆盖旧重跑、跳过部署、失败报告期限、分页、删除前状态变化、API 权限与部分删除失败。
- 风险结果写入失败、失去执行者、超时回收和任务编号隔离。
- 业务金额、规则、组合、快照、飞出、退本及精确极值。
- 0 尾逐注赔率、本命重叠优先级、配置快照、飞出与金额修改后的舍入。
- 投注人／玩法多选、投注总额升降序、非法排序参数、分页及自动刷新。
- 历史清空的密码、确认文字、会话、幂等、跨客户隔离、保留本期及备份删除／恢复阻止。
- 清空响应丢失时，同一弹窗内重试沿用请求编号；取消、关闭或 Escape 后重新打开必须生成新编号。
- 恢复预检拒绝不停止网站；停服后二次预检失败恢复服务；已开始修改数据库后的失败保持停机。
- Python 3.10 下的工件校验、篡改／缺失文件拒绝及大文件分块摘要计算。
- 应用只输出 error、Nginx 关闭访问日志及 Docker 日志轮转。
- 真实 MySQL 事务与历史数据库向前迁移；不改写历史快照。
- 托管账号的数据库权限隔离、跨客户 API 访问、单会话、密码变更和到期边界。
- 激活码账号绑定、并发核销、重试幂等、提前续期、永久授权及停用。
- 到期后旧投注结算，以及永久删除业务、账号和相关备份。
- Nginx 双域名、HTTPS Cookie、Web 管理流程、可访问性及窄屏。
- 容器启动、停止、备份、恢复、更新失败处理与 200 在线目标。

测试命令见 [开发指南](../getting-started/development.md)。通过、失败、跳过、未执行必须分别记录。未连接 VPS 时不能宣称生产部署完成；本地证书测试不能代替公网证书与 Cloudflare 验证。

本版实际结果和未验证范围见 [验收记录](verification.md)。

模块回归须覆盖默认开关、刷新持久化、单独关闭两种录注、同时关闭后的全部入口、禁用写路径、开关保存失败恢复及历史飞出保留。按投注人费率需覆盖不同投注人隔离、明确费率名称优先、重开弹窗的草稿、晚到匹配响应、无效关联导致整单回滚、玩法变更／停用，以及预览不学习。
