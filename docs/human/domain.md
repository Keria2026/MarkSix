# 领域模型

## 身份与账本

**运营管理员**管理平台客户及授权。**客户**是登录工作台并拥有独立账本的账号。**投注人**是客户账本内的姓名或代号。**接收方**是飞出投注的交易对方。

## 玩法与投注

**玩法**定义投注对象、开奖范围、命中条件、数量关系与费率。一个玩法可以有多个配置版本。

**基础注**是可以独立计算本金、反水和派彩的最小单位。普通多选、复式、拖及包肖可以产生多个基础注。

**市场**分为新澳门和香港，共用玩法配置，分别开奖与结算。未指定市场时默认新澳门。

**投注分项**保存市场、一次选项组合及其基础注、规则和费率快照。**投注单**组织同一投注人的多个分项；整单共同确认，分项分别结算。

**飞出投注**是原投注的一部分风险转移。原受注、飞出与自留分别形成统计口径。

## 期次与结算

**业务日期**按北京时间每日 06:00 划分；**期次**绑定市场、映射、投注版本和开奖结果。新澳门按业务日期建立期次；香港未开奖时跨天继续归入同一期，开奖后可补录至开奖日次日 06:00。港澳分项可组合成同一张单，但盈亏各自按所属市场结算。

**映射**定义号码与生肖的对应关系。**开奖结果**包含六个平码和一个特码，以及对应的生肖、波色和开奖时间。

**结算**使用已接受的开奖与投注快照计算派彩及盈亏。

**日报**按投注录入时的业务日期合并两个市场。香港跨天沿用同一期，不改变已记录的日报归属；每条投注保留市场及实际开奖期号。尚有待结算投注时，日报净额显示待结算。

## 金额口径

本金是接受投注的金额；反水是按费率计算的返还；派彩是命中后的支付额。和局退还本金并取消对应反水。

尾数玩法可独立设置 0 尾特殊赔率和反水。启用后，含 0 尾的基础注使用对应特殊费率，优先于本命肖费率；其余基础注沿用本命肖或普通费率。未启用时沿用现有费率。费率按录入时的玩法版本保存，后续配置修改不影响已录入投注。

客户账本的净额以本金扣除派彩和反水表示。飞出账本按相反交易方向计入自留净额。
