# 领域术语

详细规则见 [当前规范](../guides/betting.md)。金额正负号必须同时注明所属方。

| 术语               | 定义                                                                                                     |
| ------------------ | -------------------------------------------------------------------------------------------------------- |
| 平台客户           | 运营方创建的盘口方账号，拥有独立账本，与其录入的投注人不同                                               |
| 运营管理员         | 创建客户、签发激活码及管理授权的人                                                                       |
| 授权截止日         | 北京时间的最后一个可投注业务日；最后授权期可操作至次日 06:00，旧投注继续结算                             |
| 盘口方／本方       | 系统使用者，接收客户投注，并可将部分金额飞出                                                             |
| 投注人             | 原受注记录的客户姓名或代号，手工录入；同名汇总                                                           |
| 飞出受注方         | 接受本方飞出金额的另一方；与原投注人独立                                                                 |
| 投注记录           | 工作台展示的一张单据：普通单笔含一个分项，组合单含多个分项；修改与撤销保留原记录及审计至主动清空该历史期 |
| 组合单             | 同一期同投注人的多个独立投注分项组成的收据，整单原子提交、分别判定后相加，不连乘赔率                     |
| 投注分项           | 一种玩法、一个每注金额的一次选项提交；组合单包含多个分项，普通单笔只有一个分项                           |
| 基础注             | 独立判定输赢、退本、赔率和反水的最小单位                                                                 |
| 普通多选           | 按玩法数量关系生成基础注；单选玩法每选项一注，非单选严格约束候选数                                       |
| 复式               | 玩法启用且录入时选用，从 n 个候选项取 k 个形成 C(n,k) 条基础注                                           |
| 拖                 | 两项玩法从左右号码池各取一项交叉组合；多项玩法保留左边固定项，从右边补足。金额为每条基础注本金           |
| 包肖               | 单号码玩法按生肖展开号码，每肖金额均分到该肖号码，与拖的每注计价不同                                     |
| 数量关系           | 等于、不多于、不少于；约束普通选择数量及复式拆分后的基础注                                               |
| 平码／特码／全部   | 前六球／最后一球／七球，平码自身顺序不影响命中                                                           |
| 特碰／软碰         | 指定特码与平码的位置／允许两个号码互换位置                                                               |
| 二中二含特         | 两平码按普通赔率、一特一平按单独含特码赔率，逐基础注判断                                                 |
| 生肖种数／四肖亮等 | 全部七球恰好出现配置种数的不同生肖，重复生肖只计一种                                                     |
| 三中二             | 一条选 3 项、至少命中 2 项的基础注，3 项全中也算中注                                                     |
| 和局               | 大小／单双所选范围含 49，退回本金、不计有效投注、不产生反水                                              |
| 本命生肖           | 当年拥有 5 个号码的生肖，元旦自动轮换；每期固定快照                                                      |
| 特殊费率           | 号码、生肖、尾数、单双、大小基础注包含本命选项时，独立采用配置的特殊赔率／反水                           |
| 原受注             | 本方从投注人接收的完整投注，飞出不改变它                                                                 |
| 飞出               | 本方以原基础注费率向受注方投注的部分或全部金额                                                           |
| 自留               | 原受注减飞出的本金及支出；净盈亏为两种账目的本方净盈亏之和                                               |
| 含本返还           | 中奖本金 × 赔率，逐基础注舍入到分                                                                        |
| 反水               | 有效本金 × 百分比，逐基础注舍入到分，和局及撤销为零                                                      |
| 有效本金           | 排除撤销和已确认和局退款后的本金                                                                         |
| 盘口净盈亏         | 有效本金 − 中奖返还 − 反水；正数盈利                                                                     |
| 本方飞出净盈亏     | 飞出返还 + 飞出反水 − 飞出本金；受注方为其相反数                                                         |
| 已实现盈亏         | 已结算期次的净盈亏，未结算／缺失开奖显示待结算                                                           |
| 快照               | 投注规则费率与期次映射的提交时版本，后续配置不追溯                                                       |
| 精确极值           | 同一个合法七球结果下，计入飞出的自留净额最大／最小值                                                     |
| 过期结果           | 投注版本不同的风险计算结果，不能冒充当前值                                                               |
| 玩法共享文件       | 只包含规则及启用状态的 schema 1 JSON，同名导入更新并保留 ID、异名新增，不带投注或授权                    |
| 删除玩法           | 逻辑删除新投注入口，保留历史版本、快照与统计                                                             |
| 候选上限           | selection_limit，约束录入候选池，独立于基础注数量关系                                                    |
| 授权码             | MSH1 一次性随机码，绑定客户账号及凭据版本，由管理后台签发并在服务器核销                                  |
| 账号授权           | 中央控制库中的授权截止日／永久授权；由服务器按北京时间校验，不依赖浏览器时钟                             |
| 0 尾特殊赔率       | 尾数基础注含 0 时采用的独立含本赔率，优先于本命肖赔率，反水独立判断                                      |
| 清空历史           | 验证密码和确认文字后，永久删除本账号本期之前的数据及托管备份，保留本期和配置                             |
| 清空凭据           | 仅记录非实名账号 ID 和时间，独立于 SQL 备份，用于阻止恢复已清空历史                                      |
