# MarkSix · V1.0

面向盘口方的托管统计系统。客户手工录注，各自拥有独立玩法、投注和账本；运营方通过 auth 管理账号与授权，不提供投注人自助下注或支付。

客户：`https://3801.win`；auth：`https://admin.3801.win`。仅支持 Ubuntu Docker 托管部署。Rust / Axum / MySQL 8.4，Svelte 5 / TypeScript，前端采用 Liquid Glass。

Codex 提交 dev，Actions 验证；运营方验收后合并 master，由 Actions 发布同一次构建工件。dev 不部署生产，密码和密钥不进入 Git 或工件。

## 业务功能

- 接口波色展示、自动抓取、异常提示及原子结算。
- 投注人、金额筛选与纠正、撤销、飞出及原受注／飞出／自留统计。
- 玩法导入导出、自定义排序、搜索匹配、数量边界、按规则拆注、赔率和反水快照。
- 同期同投注人组合单：多玩法独立计账，整单提交、汇总、分项判定及操作。
- 投注人分类统计可逐人导出中文 PDF，对账记录打包 ZIP；客户可验证原密码自行改密。
- 号码、生肖、波色、尾数、大小、单双、生肖种数；特碰、软碰、三中二及二中二含特分档。
- 大小／单双按所选范围处理 49 退本；年度生肖与本命费率。
- 尾数玩法可设置 0 尾特殊赔率，含 0 尾的基础注逐注应用并保留快照。
- 本期统计含投注记录，自动列出已有投注人和玩法供多选筛选，支持投注总额升降序。
- 客户可验证密码后永久清空本期之前的历史及托管备份；本期、配置和授权保留。
- 同一合法开奖结果下的精确盈亏极值；过期、超时和失败明确显示。
- 账号专用激活码、提前续期、永久授权、单会话及永久删除客户。

新客户默认使用 `fixtures/customer-plays.json`（用户提供的 plays-prop，33 条玩法），按文件保留复式、赔率及反水，其中一肖中反水为 5%，其余为 10%。已有客户可预览导入：同名更新、不同名新增，历史投注保留原快照。玩法设置支持按名称搜索、在卡片内多选，批量调整开奖、数量、复式、普通及特殊费率，或批量删除；投注时间等设置位于顶部“配置设置”分区。
