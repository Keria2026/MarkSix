# MarkSix Windows 原生版（无需 Docker / WSL / Node / Rust）

适用于 Windows 10/11 x64。程序在本机运行，浏览器访问 http://127.0.0.1:8088。
包含原生 marksix.exe、前端页面和 MySQL 8.4；仅监听本机，不对局域网开放。

## 首次使用

1. 完整解压 ZIP 到固定目录，例如 `C:\MarkSix`，不要在压缩包中运行。
2. 首次使用建议运行包内微软签名的 `vc_redist.x64.exe` 安装 VC++ x64 运行库（MySQL 所需；可能提示管理员授权）。已安装对应运行库可以跳过。
3. 双击 `Install.cmd`，设置并再次确认管理员密码（至少 12 个字符）。默认账号 `admin`。
4. 等待数据库初始化和页面自动打开；之后双击 `Start.cmd` 即可使用。

所有安装、启动、停止操作使用同一个 Windows 用户。无需管理员权限运行 MarkSix。
安装包包含依赖，运行库安装完成后可离线初始化；自动获取开奖结果仍需要网络。
不安装 Windows 服务、不设置开机启动。重启电脑后需要重新运行 Start.cmd。
运行期间请保持该用户登录。

## 停止、备份与更新

- `Stop.cmd`：先停止应用，再安全关闭 MySQL。请在移动安装目录或关机前执行。
- `Backup.cmd`：运行中生成完整 MySQL SQL 备份，位于 `%LOCALAPPDATA%\MarkSix\backups`。备份包含业务数据及账号哈希，请妥善保管，并复制到其他磁盘。
- 更新：先用旧包 Stop.cmd，备份原安装包和数据目录，再解压新包并运行 Install.cmd。已有账号和数据库会保留。数据库迁移可能不支持旧版程序；回退前应恢复对应备份。
- 数据目录：`%LOCALAPPDATA%\MarkSix`，独立于程序目录。删除或覆盖此目录会丢失数据。
- config.json 中的凭据由 Windows DPAPI 加密，只能由原 Windows 用户解密。不要仅复制该文件到另一台电脑。跨机器迁移应使用 SQL 备份，由维护人员导入新初始化的 marksix 数据库；本版不提供一键恢复按钮。
- 原 Docker 部署的数据不会自动迁入原生数据库。请先导出原数据库再安排迁移。

## 故障排查

- 8088 为网页端口，33306 为数据库端口；被占用时会停止并报错，不会结束其他程序。请先关闭占用程序（包括原 Docker 部署）。
- 窗口提示缺少 DLL / MySQL 无法启动：安装包内 vc_redist.x64.exe 后重试，必要时重启 Windows。
- 数据目录内的 `mysql-error.log`、`app.stdout.log`、`app.stderr.log` 可用于诊断。
- 首次初始化中断且已有部分数据库文件：程序会保留现场并拒绝覆盖，请先检查日志，不要盲目删除数据。
- 不要同时启动不同目录的两个版本。
- manifest.json 记录构建提交、MySQL 下载来源和文件 SHA256；启动前检查文件完整性。

MySQL 的版权、许可证及附带文档保留在 mysql 目录；VC++ 运行库采用微软自带安装条款。
